Super MiniTV Ultra media storage

Put media under:

Videos/1/
Videos/2/
Videos/random/

Each numbered channel should contain one .mjpeg file and a matching .aac or .mp3 file.
The random folder can contain multiple matching .mjpeg + .aac/.mp3 pairs.

Recommended video:
240x240, 24 fps, baseline JPEG/MJPEG.

Recommended audio:
AAC or MP3, 44.1 kHz, modest bitrate.

The web console can also upload media files into the LittleFS media tree.
